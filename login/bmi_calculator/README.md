# BMI-Rechner (HTML, CSS, JavaScript)

Ein interaktiver BMI-Rechner, den ich zur Vertiefung meiner Webentwicklungs-Kenntnisse erstellt habe.

## Funktionen
- Eingabe von Größe (cm) und Gewicht (kg)
- Berechnung des BMI in Echtzeit ohne Neuladen der Seite
- Kategorisierung des Ergebnisses (Untergewicht, Normalgewicht, Übergewicht, Adipositas)
- Responsives und modernes Design mit CSS

## Verwendete Technologien
- HTML5
- CSS3 (Flexbox, Box-Shadow, Hover-Effekte)
- JavaScript (DOM-Manipulation, Funktionen, Bedingungen)

## Installation & Ausführung
Einfach die Datei indexBMI.html im Browser öffnen.

## Was ich gelernt habe
- Verbindung von HTML, CSS und JavaScript in einem Projekt
- Arbeiten mit dem DOM (getElementById, innerText)
- Bedingte Logik zur Kategorisierung von Werten
- Gestaltung einer benutzerfreundlichen Oberfläche
